# TaskFlow

Aplicativo mobile desenvolvido como projeto de TCC do curso de Análise e Desenvolvimento de Sistemas.

O TaskFlow é uma plataforma para intermediação de serviços freelancers sob demanda, conectando empresas/contratantes a profissionais autônomos de forma rápida, organizada e segura.

A proposta do sistema envolve cadastro de usuários, publicação de chamados, candidatura de freelancers, aceite/recusa pela empresa, pagamento de taxa, chat liberado após confirmação, conclusão do serviço, avaliações mútuas e notificações. :contentReference[oaicite:0]{index=0}

---

## Tecnologias utilizadas

Este projeto está sendo desenvolvido com:

- React Native
- Expo
- TypeScript
- Expo Router
- React Native SVG
- React Native SVG Transformer

Stack planejada para a versão completa do TCC:

- Front-end: React Native
- Back-end: C# com ASP.NET Core
- Banco de dados: MySQL
